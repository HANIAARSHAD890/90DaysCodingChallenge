# 🌐 6 Days Web Development Challenge

This repository contains a collection of **simple websites built over 6 days** as part of a frontend web development practice challenge. Each day focuses on improving HTML and CSS skills by building a small, standalone website.

---

## 📁 Repository Structure

6-days-web-dev/
- day01/ – Gym Website (HTML & CSS)  
- day02/ – Gym Website (Improved version)  
- day03/ – CSS Brand Website  
- day04/ – Cakes Website using CSS  
- day05/ – Flowers Website  
- day06/ – Basic Website built with HTML & CSS

- CSS3
